snap-website

Capture a screenshot of any URL and get it back as an image. Use the form below to try the API.

Endpoint

GET/website-to-blob-img
Param Type Description
url required string Page URL to capture
format string png (default), jpeg, or webp
width number Viewport width in px (default 1280)
height number Viewport height in px (default 720)
wait number Extra settle time in ms after network idle (optional)
